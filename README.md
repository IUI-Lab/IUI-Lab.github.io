# IUI-Lab.github.io

# 使い方

初回インストール

```
npm install
```

コンテンツ更新時のライブプレビュー

```console
npm run dev
```

以下でコンテンツのビルド

```console
npm run build
```

ビルドしたコンテンツのプレビュー

```console
npm run preview
```
